# Tavo · Идеи для сюжета — расширение для SillyTavern

Панель под последним сообщением бота: карусель вариантов развития сюжета (ходы **бота**) с типами
(Драма/Романтика/Спокойствие/Напряжение/Тайна/Неожиданное), цветами и летающими бабочками. Кнопки:
- **▶️ пусть бот так и сделает** — генерит полный ход бота в выбранном направлении и дописывает его в чат;
- **🎲 Рискнуть** — сюрприз-ход, не показывая заранее;
- **🙈 подсмотреть** — короткий тизер намёка;
- **🔄 другие варианты** — реролл.

Это порт плашки из Tavo. Отличие: генерация идёт **через уже настроенное в SillyTavern подключение**
(твоя модель + пресет), никакого отдельного ключа/прокси не нужно.

## Как работает генерация
- **Варианты и тизер** — `generateRaw` (мета-задача вне чата: не засоряет историю, не тянет карточку персонажа).
- **Полный ход бота** — `generateQuietPrompt` в «громком» режиме, результат дописывается как сообщение персонажа.

Варианты и состояние «свёрнуто/развёрнуто» хранятся в `extra` самого сообщения — переживают перезаход в чат.
По умолчанию панель **свёрнута** (как в Tavo) — клик по заголовку разворачивает.

## Установка (вручную, без GitHub)
1. Найди папку расширений SillyTavern:
   - обычно `SillyTavern/data/<твой-логин>/extensions/`
   - (или, в старых сборках, `SillyTavern/public/scripts/extensions/third-party/`)
2. Скопируй туда **всю папку** `st-tavo-ideas` целиком (с `manifest.json`, `index.js`, `style.css`).
3. Перезапусти/обнови SillyTavern в браузере (F5).
4. Открой чат — под последним ответом бота появится свёрнутая плашка «🎬 варианты развития».

Проверить, что расширение подхватилось: Extensions (иконка-кубик) → в списке будет «Tavo · Идеи для сюжета».
В консоли браузера (F12) при загрузке будет строка `[tavo-ideas] загружено`.

## Установка по URL (если выложишь на GitHub)
Extensions → **Install Extension** → вставь URL репозитория. Требуется, чтобы `manifest.json` лежал в корне репо.

## Требования
- Свежая версия SillyTavern (API `getContext()` с `generateRaw`/`generateQuietPrompt` в объектной форме —
  сборки 2024+). Если что-то не генерит — проверь, что в SillyTavern выбрано рабочее подключение к модели.

## Настройки (правятся вверху `index.js`)
- `VARIANTS_COUNT` — сколько вариантов (по умолчанию 5);
- `SHOW_MYSTERY` — показывать ли карточку-загадку (по умолчанию да);
- `CONTEXT_MESSAGES` — сколько последних сообщений уходит модели как транскрипт (по умолчанию 12).
